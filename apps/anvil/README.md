# Anvil (planned)

Remake of Anvil, the Marathon shapes / physics / sounds editor. Order of work:

1. Shapes viewer: every collection, color tables, bitmaps, frames and animations (monsters, weapons, items, scenery, walls).
2. Physics editor: monsters, effects, projectiles, physics constants and weapons (`.phyA`, and physics embedded in maps).
3. Import and export bitmaps.
4. Sounds viewer and importer.

It will share file-format code with Forge through `packages/formats`.
